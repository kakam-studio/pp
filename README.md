บทบาท: คุณเป็นนักพัฒนาเว็บที่เชี่ยวชาญงานเอกสารราชการไทยและการจัดหน้ากระดาษสำหรับพิมพ์

เป้าหมาย: สร้างเว็บ "ระบบแม่แบบเอกสาร" สำหรับ [ชื่อหน่วยงาน/โรงเรียน] ให้ครูกรอกข้อมูลแล้ว
ได้เอกสารที่หน้าตาเหมือนต้นฉบับที่แนบมา เอกสารแรกคือ [ชื่อเอกสาร เช่น บันทึกข้อความขออนุญาตไปราชการ]

ไฟล์ต้นฉบับ: [แนบไฟล์] — ให้อ่านไฟล์ต้นฉบับจริงก่อนเริ่ม (ตำแหน่งข้อความ ฟอนต์ ขนาด ระยะขอบ เส้นตาราง โลโก้)
แล้วสรุปให้ฉันตรวจก่อนลงมือเขียนโค้ด ว่ามีช่องกรอกอะไรบ้างและวางตรงไหน

สถาปัตยกรรม (สำคัญ):
1. แยก "ตัวกลาง" กับ "แม่แบบ" — แม่แบบ 1 ไฟล์ต่อเอกสาร ประกอบด้วย id, name, type ('grid' สำหรับ
   ปก/แบบฟอร์มตำแหน่งตายตัว, 'flow' สำหรับเอกสารเนื้อความหลายหน้า), page (ขนาด, ระยะขอบ มม., ฟอนต์),
   fields (key เป็นภาษาอังกฤษไม่มีจุด, label ภาษาไทย, type, ค่าเริ่มต้น, required, shared) และ layout(data)
2. layout เป็นผังเดียว ใช้สร้างทุกแบบ: ตัวอย่างบนจอ (HTML), พิมพ์, .pdf, .docx และ .xlsx (เฉพาะแบบ grid)
3. มีชิ้นส่วนสำเร็จรูปใช้ร่วมกัน: โลโก้/ครุฑ, หัวเรื่อง, ช่องคำนำหน้า+ข้อมูลพร้อมเส้นจุด, ตาราง,
   ช่องวงกลมอนุมัติ/ไม่อนุมัติ, บล็อกลงชื่อ (ชื่อในวงเล็บ + ตำแหน่ง + วันที่), ย่อหน้าเนื้อความ
4. ข้อมูลส่วนกลาง (ชื่อหน่วยงาน, โลโก้, ผู้บริหาร, รายชื่อครู) ตั้งค่าครั้งเดียวแล้วใช้ได้ทุกแม่แบบ

ฟังก์ชันที่ต้องมี:
- หน้าแรกเลือกเอกสาร / แบบฟอร์มสร้างจาก fields อัตโนมัติ / ตัวอย่างอัปเดตทันทีขณะพิมพ์
- โหมดการแสดงผล 2 แบบ: "กรอกข้อมูลเต็มหน้า" และ "กรอกข้อมูล + แสดงผล" (ลากปรับความกว้างได้, ย่อ/ขยายตัวอย่างได้)
- ทำได้หลายชุดในครั้งเดียว (เพิ่ม/ทำสำเนา/ลบ) และเลือกได้ว่าจะบันทึก/พิมพ์ "ชุดนี้" หรือ "ทุกชุด"
- บันทึกเป็น .docx (ไลบรารี docx), .xlsx (ExcelJS), .pdf และพิมพ์ (@page A4)
- นำเข้า .xlsx ตามแม่แบบ พร้อมรายงานว่าช่องใดอ่านไม่ได้; มีปุ่มดาวน์โหลดไฟล์ .xlsx เปล่าสำหรับกรอก
- ตั้งระยะขอบได้ (มม.) และย่อความสูงแถวอัตโนมัติไม่ให้ล้นหน้า (แบบ grid) / ตัดขึ้นหน้าใหม่อัตโนมัติ (แบบ flow)
- วันที่แบบ พ.ศ. (Intl th-TH-u-ca-buddhist) และให้เลือกใช้เลขไทยได้
- ชื่อไฟล์ตอนบันทึก: [รูปแบบ เช่น MEMO-ปีการศึกษา-ภาคเรียน-สุ่ม6ตัว]
- บันทึกข้อมูลอัตโนมัติใน localStorage (ครอบ try/catch) และมีปุ่มสำรอง/กู้คืนเป็นไฟล์ JSON

เทคนิคและข้อจำกัด:
- HTML/CSS/JS ล้วน ไม่ต้องติดตั้งหรือ build เปิดไฟล์ index.html ได้เลย; ไลบรารีจาก cdnjs/unpkg ระบุเวอร์ชันชัดเจน
- ฟอนต์ไทย: ใช้ [TH Sarabun New / TH SarabunIT๙] ถ้าเครื่องไม่มีให้ใช้ Sarabun ปรับขนาดให้ใกล้เคียง
  และบอกผู้ใช้บนหน้าจอว่ากำลังใช้ฟอนต์อะไร
- ข้อมูลทั้งหมดประมวลผลในเบราว์เซอร์ ห้ามส่งข้อมูลไปเครื่องแม่ข่ายใด ๆ (ข้อมูลนักเรียน/บุคลากร)
- หน้าเว็บภาษาไทย ใช้ง่ายสำหรับครูที่ไม่ถนัดคอมพิวเตอร์ รองรับมือถือ

การทดสอบก่อนส่งมอบ (ต้องทำจริงและรายงานผล):
1. นำเข้าไฟล์ต้นฉบับที่แนบ แล้วข้อมูลทุกช่องต้องตรง
2. ส่งออก .xlsx แล้วนำเข้ากลับ ต้องได้ข้อมูลเหมือนเดิมทุกช่อง (ทดสอบช่องที่มีจุด เช่น เกรด 3.5 ด้วย)
3. เปิด .docx/.xlsx ที่ส่งออกด้วย Word/Excel ต้องได้ 1 หน้าต่อ 1 ชุด (แบบ grid) และไม่มีหน้าว่าง
4. เปลี่ยนระยะขอบแล้วตรวจว่ายังพอดีหน้า
5. ทดสอบข้อความยาวผิดปกติ ช่องว่าง และตัวเลข 0
